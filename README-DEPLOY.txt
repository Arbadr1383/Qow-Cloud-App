نسخه ابری حسابداری قو

- نسخه قبلی Electron را حذف نکن.
- این پوشه را برای Cloudflare Pages استفاده کن.
- یک D1 با نام qow-accounting-db بساز و ID آن را در wrangler.toml وارد کن.
- schema.sql را روی Remote D1 اجرا کن.
- Pages را Deploy کن.
- اولین ورود با همان اطلاعات برنامه، داده‌های لپتاپ را به D1 منتقل می‌کند.
- سپس از «کاربران و دسترسی» دو حساب بساز: یکی لپتاپ، یکی موبایل.
- روی موبایل و لپتاپ همان آدرس سایت را باز کن و آن را به Home Screen / Install App اضافه کن.
